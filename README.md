# User-configuration-manager

A Python program for managing user settings. It lets you add, update, remove, and view settings from one place.

## Features

- **Add settings:** Create a new setting with a name and value
- **Update settings:** Change the value of an existing setting
- **Remove settings:** Delete a setting you no longer need
- **View settings:** Display all saved settings

## How to Run

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Run the program:

   python main.py

## Example

Add a setting:      theme = dark
Update a setting:   theme = light
View settings:      theme: light
Remove a setting:   theme
